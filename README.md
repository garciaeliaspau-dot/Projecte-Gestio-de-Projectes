# EcoUAB - Gestió sostenible dels residus

## 1. Descripció del projecte
El nostre projecte consisteix a millorar la gestió dels residus al campus de la Universitat Autònoma de Barcelona (UAB), facilitant el reciclatge i promovent hàbits sostenibles entre els estudiants.

## 2. Objectius i finalitats
- Millorar la separació i el reciclatge dels residus a la UAB.
- Facilitar informació sobre els diferents tipus de residus.
- Ajudar els estudiants a identificar els contenidors adequats.
- Fomentar la conscienciació ambiental dins del campus.

## 3. Criteris mínims d'èxit
- Crear una pàgina web funcional i fàcil d'utilitzar.
- Desenvolupar un prototip interactiu per identificar on llençar cada residu.
- Incloure informació útil sobre reciclatge i punts de recollida.
- Planificar les tasques mitjançant un diagrama de Gantt.
- Organitzar el treball amb un tauler Kanban a GitHub.

## 4. Distribució dels rols
- **Integrant 1:** Coordinació i planificació del projecte.
- **Integrant 2:** Desenvolupament de la pàgina web.
- **Integrant 3:** Recerca d'informació i continguts.
- **Integrant 4:** Disseny i desenvolupament del prototip.

Tots els membres col·laboraran en les diferents fases del projecte.
